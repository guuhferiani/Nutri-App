2. Detalhamento por Plataforma

🐙 GitHub (Código & Controle)
Ilimitado
• Repositórios públicos e privados sem custos.
• Colaboradores ilimitados por projeto.
• Histórico Git completo e proteção de branches.
▲ Vercel (Hospedagem Frontend)
100 GB / mês
• Deploys automáticos a cada git push.
• Até 100 deploys diários na branch principal.
• CDN Global de alta velocidade com Edge Caching.
🐘 Neon Serverless Postgres (Banco de Dados & Autenticação)
• 512 MB na prática: Como registros de pacientes, anamnese e consultas são texto e números (1 a 2 KB por cadastro), 512 MB comportam anos de operação de uma clínica.
• Auto-suspend e Cold Start: O banco entra em repouso após 5 min de inatividade para economizar recursos e religa em ~500ms na primeira requisição.
• Connection Pooling: Suporta até 10.000 conexões simultâneas através da porta pooler, evitando quedas em picos de tráfego web.
• Segurança & Backup: Row Level Security (RLS) nativo e 24 horas de histórico para restauração pontual (*Point-in-Time Restore*).

3. Boas Práticas de Escalabilidade

💡 Dica para Armazenamento de Arquivos:
Para manter o banco de dados sempre leve e rápido, nunca armazene arquivos pesados (fotos de exames, PDFs ou imagens de antes/depois) em formato binário direto no PostgreSQL. A melhor prática é hospedar os arquivos em um serviço como AWS S3, Supabase Storage ou Cloudinary e gravar no Neon apenas a URL do arquivo.
